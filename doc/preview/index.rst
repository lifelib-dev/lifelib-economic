Preview of the economic library's pages
=======================================

This is a local build of the documentation pages that this repository drafts for
lifelib's **economic** library, made with lifelib's Sphinx settings: the library's
page, the model pages and their generated space pages, the notebooks and the gallery.

* :doc:`libraries/economic/index`
* :doc:`generated_examples/economic/index`

The rest of lifelib's documentation is not built here, and links to it lead to
`lifelib.io <https://lifelib.io>`_. In lifelib, this page is the home page, and the
gallery holds every library's examples.
